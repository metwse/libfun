Detailed Description

Basic hashmap.

#define T <key-type>, <value-type>, <name>[, (<flags>)]
// Function to override hash function input.
#define fmap_key <map-key-fn>
// Function takes key type as input and returns its hash.
#define fuse_hash <hash-fn>
// map_key function should have the signature:
void my_map_key(const key_type *key,
size_t key_len,
const char **out_bytes,
size_t *out_len)
{
// default implementation
*out_len = key_len;
*out_bytes = &key;
}
// hash function should have signature:
uint64_t my_hash(const char *key, size_t key_len)
{
// default implementation is the FNV hash function.
...
}

This implementation uses open addressing method. It allows variable-length keys while storing fixed-length values.

◆ fhmap_reserve()

static int fhmap_reserve ( struct fhmap *  m,
size_t  additional 
)
inlinestatic

Reserves capacity for at least additional more elements to be inserted in the hashmap.

The collection may reserve more space to speculatively avoid frequent reallocations.

Note
This operation is best-effort grow, the capacity may left as-is if a memory allocation failure occur.

Returns non-zero if a memory allocation failure occurs.

◆ fhmap_shrink_to_fit()

static int fhmap_shrink_to_fit ( struct fhmap *  m)
inlinestatic

Shrinks the hashmap to ~133% of its used element count, if its capacity is larger than that.

Use hmap_shrink_to(&m, 0) if you really want to shrink the capacity of the map as much as possible.

Note
This operation is best-effort shrink, the capacity may left as-is if a memory allocation error occur.

Returns non-zero if a memory allocation failure occurs.
